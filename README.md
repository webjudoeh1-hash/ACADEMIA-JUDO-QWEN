# Academia de Judo

Aplicación web para gestión de contenido privado de una academia de judo.

## Tecnologías

- Next.js
- Tailwind CSS
- Supabase (autenticación, base de datos, almacenamiento)
- Vercel (despliegue)

## Instalación

1. Clonar el repositorio
2. Ejecutar `npm install`
3. Crear archivo `.env.local` con las variables de Supabase
4. Ejecutar `npm run dev`

## Uso

- El administrador puede subir y eliminar archivos.
- Los usuarios pueden ver y descargar archivos.
